# DevOps

Connect the both application using docker compose.

## Compose in many ways:

- Standard(It's will keep install all the packages every time you excute `docker compose up`)

- Pointer to docker files(You have option docker compose build which helps you to `docker compose up` without install the all packages)

### Compose commands: 

- docker compose up 

- docker compose down

- docker compose start (all the services or one service)

- docker compose stop (all the services or one service)

- docker compose build ---> to build the images before run the service
